1. Starting Point: What We Actually Do During Training

Forget fancy probability words for a moment. Think about what happens inside the training loop in the most down-to-earth way.

  1. You take one training example – a center–context pair \((w_i, c_i)\).
  2. The model predicts a probability \(p_{\text{model}}(c_i \mid w_i)\).
  3. You compute some loss number \(\ell_i\) from that probability.
  4. You add it to the total loss, move to the next example, and so on.

From the previous posts, we decided that the most natural per-example loss is the surprise:

\[ \ell_i \;=\; -\log p_{\text{model}}(c_i \mid w_i). \]

If the model assigns high probability to the actual context, \(\ell_i\) is small. If it assigns low probability, \(\ell_i\) is large. This is exactly what we want.

After going through all \(N\) training examples, we compute the average:

\[ L_{\text{empirical}} \;=\; \frac{1}{N} \sum_{i=1}^{N} \big( -\log p_{\text{model}}(c_i \mid w_i) \big). \]

This is the quantity the optimizer is actually minimizing. So the big question becomes:

What does this average really mean, in terms of probability?

2. Looking at the Data as Counts

Let’s step back and look at the dataset as a big bag of (center, context) pairs. Some pairs appear often, some rarely, some never.

Imagine we tabulate how many times each pair appears:

Pair \((w, c)\) Count in corpus
\((\text{love}, \text{my})\) \(\text{count}(\text{love}, \text{my})\)
\((\text{love}, \text{You})\) \(\text{count}(\text{love}, \text{You})\)
\((\text{my}, \text{dog})\) \(\text{count}(\text{my}, \text{dog})\)
... ...

The total number of training pairs is:

\[ N \;=\; \sum_{w, c} \text{count}(w, c). \]

Now recall the empirical average loss:

\[ L_{\text{empirical}} \;=\; \frac{1}{N} \sum_{i=1}^{N} \big( -\log p_{\text{model}}(c_i \mid w_i) \big). \]

We can regroup this sum by unique pairs \((w, c)\). Every time the same pair appears, it contributes the same \(-\log p_{\text{model}}(c \mid w)\).

So we can rewrite:

\[ L_{\text{empirical}} \;=\; \frac{1}{N} \sum_{w, c} \text{count}(w, c) \cdot \big( -\log p_{\text{model}}(c \mid w) \big). \]

This is the same number, just written in a more structured way: we are summing over all (center, context) pairs, weighted by how often they appear in the corpus.

3. From Counts to an Empirical Data Distribution

Now comes the key conceptual shift. Whenever you see count / N, you should think: “Ah, that looks like a probability.”

Define the empirical joint probability:

\[ p_{\text{data}}(w, c) \;=\; \frac{\text{count}(w, c)}{N}. \]

This simply says:

If I randomly pick one pair from the dataset, the chance it is \((w, c)\) is \(p_{\text{data}}(w, c)\).

Using this, we can rewrite the empirical loss compactly:

\[ L_{\text{empirical}} \;=\; \sum_{w, c} p_{\text{data}}(w, c) \cdot \big( -\log p_{\text{model}}(c \mid w) \big). \]

Now the expression is starting to look like an expectation: “sum of probability times value”.

4. Splitting the Data Distribution: Center and Context

The joint probability \(p_{\text{data}}(w, c)\) can be factored as:

\[ p_{\text{data}}(w, c) \;=\; p_{\text{data}}(w)\, p_{\text{data}}(c \mid w). \]

Here:

  • \(p_{\text{data}}(w)\) is “how often does this center word \(w\) appear in the corpus?”
  • \(p_{\text{data}}(c \mid w)\) is “given that the center is \(w\), how often is the context \(c\)?”

Substitute this into the loss:

\[ L_{\text{empirical}} \;=\; \sum_{w, c} p_{\text{data}}(w)\, p_{\text{data}}(c \mid w) \cdot \big( -\log p_{\text{model}}(c \mid w) \big). \]

Rearrange the sums (sum over \(w\) outside, contexts inside):

\[ L_{\text{empirical}} \;=\; \sum_{w} p_{\text{data}}(w) \left[ \sum_{c} p_{\text{data}}(c \mid w) \cdot \big( -\log p_{\text{model}}(c \mid w) \big) \right]. \]

Inside the square brackets, look at the inner sum:

\[ L(w) \;=\; \sum_{c} p_{\text{data}}(c \mid w) \cdot \big( -\log p_{\text{model}}(c \mid w) \big). \]

This is the average surprise of the model for a fixed center word \(w\), when contexts are drawn according to the data distribution.

So the full loss is:

\[ L_{\text{empirical}} \;=\; \sum_{w} p_{\text{data}}(w)\, L(w). \]

In words:

The total loss is the average (over center words \(w\)) of the model’s average surprise over contexts \(c\) drawn from \(p_{\text{data}}(c \mid w)\).

5. Zooming In on \(L(w)\): A Probability–Probability Comparison

Let’s stare at \(L(w)\) again:

\[ L(w) \;=\; \sum_{c} p_{\text{data}}(c \mid w) \cdot \big( -\log p_{\text{model}}(c \mid w) \big). \]

This expression is doing something very specific:

  • It takes the true probabilities \(p_{\text{data}}(c \mid w)\)
  • and compares them with the model probabilities \(p_{\text{model}}(c \mid w)\)
  • by computing an average of \(-\log p_{\text{model}}(c \mid w)\) weighted by \(p_{\text{data}}(c \mid w)\).

In expectation notation, you can write:

\[ L(w) \;=\; \mathbb{E}_{c \sim p_{\text{data}}(\cdot \mid w)} \left[ -\log p_{\text{model}}(c \mid w) \right]. \]

So: if nature chooses contexts according to \(p_{\text{data}}(\cdot \mid w)\), \(L(w)\) tells you the model’s average surprise about what actually happens.

6. Now We Name It: Cross-Entropy

Up to this point, we have only used basic ideas:

  • per-example surprise = \(-\log p_{\text{model}}\)
  • average over the dataset
  • rewriting that average using frequencies and probabilities

What we have arrived at for a fixed center word \(w\) is:

\[ L(w) \;=\; \sum_{c} p_{\text{data}}(c \mid w) \cdot \big( -\log p_{\text{model}}(c \mid w) \big). \]

This exact pattern appears in information theory and is given a name: cross-entropy.

Given two distributions \(P(c)\) and \(Q(c)\) over the same outcomes, the cross-entropy of \(P\) with respect to \(Q\) is:

\[ H(P, Q) \;=\; \sum_{c} P(c)\, \big( -\log Q(c) \big). \]

If you set:

  • \(P(c) = p_{\text{data}}(c \mid w)\)
  • \(Q(c) = p_{\text{model}}(c \mid w)\)

then:

\[ L(w) \;=\; H\!\left( p_{\text{data}}(\cdot \mid w), \;p_{\text{model}}(\cdot \mid w) \right). \]

So the loss for a single center word \(w\) is precisely the cross-entropy between:

  • the distribution that the data uses to pick contexts, and
  • the distribution that the model predicts for contexts.

7. Intuition: Why Minimizing Cross-Entropy Makes Sense

Now that we know our loss is cross-entropy, what does minimizing it mean, intuitively?

  • If \(p_{\text{data}}(c \mid w)\) is large (the context really does appear often in the data), and the model sets \(p_{\text{model}}(c \mid w)\) too small, then the term \(p_{\text{data}}(c \mid w)\,(-\log p_{\text{model}}(c \mid w))\) is large → big contribution to the loss.
  • The only way for the model to reduce this contribution is to raise \(p_{\text{model}}(c \mid w)\) closer to \(p_{\text{data}}(c \mid w)\).
  • If the model wastes probability mass on contexts that almost never appear in the data, it must reduce probability on common contexts (because probabilities must sum to 1), which again increases the loss.

So minimizing cross-entropy forces the model to:

  • assign high probability to events that are common in the data,
  • assign low probability to events that are rare or absent in the data,
  • and in the end, make \(p_{\text{model}}(\cdot \mid w)\) track \(p_{\text{data}}(\cdot \mid w)\) as closely as possible.
Cross-entropy is just the formal name for “average surprise of the model when reality follows the data”.

The real problem is choosing the direction

Let me say clearly what changed between Blog 2 and Blog 3.

In Blog 2, we pretended the direction of the line \(w\) was already known. Under that assumption, the only question left was this. For a single point \(x\), where should its proxy \(c\,w\) sit on that line. That is why we solved for the best \(c^*\).

Now I want to remove that assumption. In a real dataset, nobody hands us the correct direction \(w\). We have to choose it.

Suppose we have \(n\) points in \(d\) dimensions:

\[ x_1, x_2, \dots, x_n \in \mathbb{R}^d \]

Imagine I propose a direction \(w\). The moment I propose it, something automatic happens. Every data point \(x_i\) gets forced onto that direction by proxy representation.

For each point, we choose the best proxy on the line spanned by \(w\). That means we pick a scalar \(c_i\) so that \(c_i w\) is the closest point on the line to \(x_i\). This gives us one proxy per point:

\[ x_i \longrightarrow \hat{x}_i = c_i w \]

And because we are compressing, we accept that the proxy will not match the original perfectly. So each point also produces an error vector:

\[ r_i = x_i - \hat{x}_i \]

Here is the main shift.

In Blog 2, we judged a direction \(w\) using one point. In Blog 3, we must judge a direction \(w\) using the entire dataset. Because if \(w\) is a bad choice, it does not just hurt one reconstruction. It forces every point to be badly represented.

So the dataset-level goal becomes: choose \(w\) so that the total reconstruction error across all points is as small as possible.

\[ \text{Choose } w \text{ to minimize } \sum_{i=1}^{n} \|x_i - \hat{x}_i\|^2 \]

This is the entire focus of Blog 3. We are not solving for the proxy of one point anymore. We are choosing the direction of the line itself so that proxies for all points become as accurate as possible.

Figure 1 — Different choices of direction \(w\) create different proxies for every point, which changes the total reconstruction error across the dataset.

Writing down the total reconstruction error

Now that the role of the direction \(w\) is clear, we need a precise way to judge whether a proposed direction is good or bad. The only honest way to do this is to look at what happens to every point when we force it to use that direction.

Fix a direction \(w\). For each data point \(x_i\), we already know what its best proxy looks like. It is the projection of \(x_i\) onto the line spanned by \(w\).

Since we are enforcing \(\|w\| = 1\), the proxy for \(x_i\) is:

\[ \hat{x}_i = (x_i^\top w)\,w \]

This step is important conceptually. Once \(w\) is fixed, there is no freedom left in choosing the proxy. Each point is automatically mapped to the closest point on the line.

That mapping produces an error vector for every point:

\[ r_i(w) = x_i - (x_i^\top w)\,w \]

Each error vector tells us how much information is lost when the point is represented using the direction \(w\). Some points may be represented well. Others may not.

The question is how to combine these individual errors into a single quantity that evaluates the direction \(w\).

The most natural choice is to look at the squared length of each error vector and add them up. Squaring ensures that large errors are penalized more heavily and that positive and negative deviations do not cancel each other.

\[ \text{Total error}(w) = \sum_{i=1}^{n} \|x_i - (x_i^\top w)\,w\|^2 \]

This expression does exactly what we want. For a given direction \(w\), it measures how much reconstruction error we accumulate when every point is forced to use that direction for compression.

If the data is well aligned with \(w\), most projections will be close to the original points and the total error will be small. If the data spreads away from \(w\), the projections will be poor and the total error will be large.

At this stage, the learning problem has a very clear mathematical form. We are looking for the direction \(w\) that minimizes this total reconstruction error.

\[ \min_{\|w\| = 1} \sum_{i=1}^{n} \|x_i - (x_i^\top w)\,w\|^2 \]

Everything that follows in this series is about understanding and solving this optimization problem. The next step is to simplify this expression so that we can see more clearly what it is really trying to optimize.

Simplifying the objective: separating what depends on \(w\)

We now have a clean mathematical statement of the problem. Choose a unit direction \(w\) that minimizes the total reconstruction error:

\[ \sum_{i=1}^{n} \|x_i - (x_i^\top w)\,w\|^2 \]

Before trying to solve this, it helps to understand its structure. In particular, we want to see which parts of this expression actually depend on the choice of \(w\), and which parts do not.

Let us focus on a single term inside the sum. Consider the squared error for one point \(x_i\):

\[ \|x_i - (x_i^\top w)\,w\|^2 \]

We expand this expression using the same idea as before. Write the squared norm as an inner product:

\[ (x_i - (x_i^\top w)\,w)^\top (x_i - (x_i^\top w)\,w) \]

Expanding term by term gives:

\[ x_i^\top x_i - 2 (x_i^\top w)(w^\top x_i) + (x_i^\top w)^2 (w^\top w) \]

Recall that \(w\) has unit length. This means \(w^\top w = 1\). Using this, the expression simplifies to:

\[ \|x_i\|^2 - (x_i^\top w)^2 \]

This result is worth pausing on. The squared reconstruction error for a point splits cleanly into two parts.

The first term, \(\|x_i\|^2\), depends only on the data point itself. It does not depend on the direction \(w\) at all.

The second term, \((x_i^\top w)^2\), depends entirely on how well the point aligns with the direction \(w\). If the point lies mostly along \(w\), this term is large. If the point is nearly orthogonal to \(w\), this term is small.

Now substitute this simplified form back into the total error.

\[ \sum_{i=1}^{n} \|x_i - (x_i^\top w)\,w\|^2 = \sum_{i=1}^{n} \|x_i\|^2 - \sum_{i=1}^{n} (x_i^\top w)^2 \]

This decomposition reveals something important.

The first sum, \(\sum_i \|x_i\|^2\), is completely independent of \(w\). No matter which direction we choose, this term remains the same.

The second sum, \(\sum_i (x_i^\top w)^2\), is the only part that changes when we change \(w\).

Because of this, minimizing the total reconstruction error is equivalent to maximizing the second term.

\[ \min_{\|w\|=1} \sum_{i=1}^{n} \|x_i - (x_i^\top w)\,w\|^2 \quad \Longleftrightarrow \quad \max_{\|w\|=1} \sum_{i=1}^{n} (x_i^\top w)^2 \]

This reformulation is conceptually useful. Instead of thinking in terms of minimizing error, we can think in terms of choosing a direction that captures as much of the data as possible when projected onto it.

The next step is to understand how to work with this new objective, and how to rewrite it in a form that exposes its structure more clearly.

Why minimizing reconstruction error becomes maximizing projection

The last section ended with a statement that can feel like a trick if we do not explain it slowly. We started with a goal that sounds like this: pick \(w\) so that the reconstruction error is as small as possible.

Then suddenly we rewrote the problem and it started sounding like this: pick \(w\) so that the projections \((x_i^\top w)\) are as large as possible.

If you do not build intuition here, it can feel like we changed the problem. We did not. We only changed the way we describe the same quantity.

Let us go back to one data point first. Fix a unit vector \(w\), and take a single point \(x_i\). We represent \(x_i\) using its proxy on the line spanned by \(w\):

\[ \hat{x}_i = (x_i^\top w)\,w \]

Now look at the point \(x_i\) as being split into two pieces. One piece lies along the direction \(w\). The other piece lies perpendicular to \(w\).

The proxy \(\hat{x}_i\) keeps only the piece along \(w\). The reconstruction error keeps only the perpendicular leftover.

Figure 2 — A point \(x_i\) decomposed into its projection on the line spanned by \(w\) and the perpendicular residual error.

This is why the squared error simplifies to:

\[ \|x_i - (x_i^\top w)\,w\|^2 = \|x_i\|^2 - (x_i^\top w)^2 \]

The term \(\|x_i\|^2\) is fixed because the point is fixed. The only thing that changes with \(w\) is the projection term \((x_i^\top w)^2\).

Now here is the key relationship.

For a fixed point \(x_i\), you cannot change \(\|x_i\|^2\). It is a constant number. So the only way to make the error small is to make the projection term large.

Another way to say the same thing is: the squared length of a vector equals the squared length of its projection along \(w\) plus the squared length of its leftover perpendicular part. If one part increases, the other part must decrease.

Now extend this idea to the dataset.

\[ \sum_{i=1}^{n} \|x_i - (x_i^\top w)\,w\|^2 = \sum_{i=1}^{n} \|x_i\|^2 - \sum_{i=1}^{n} (x_i^\top w)^2 \]

The first term, \(\sum_i \|x_i\|^2\), is still constant with respect to \(w\). We are not changing the data points. We are only changing the direction we choose to represent them.

So when we change \(w\), the only thing that changes is the second term. That means the direction that minimizes the total error is exactly the direction that maximizes the total squared projection.

\[ \min_{\|w\|=1} \sum_{i=1}^{n} \|x_i - (x_i^\top w)\,w\|^2 \quad \Longleftrightarrow \quad \max_{\|w\|=1} \sum_{i=1}^{n} (x_i^\top w)^2 \]

This is a very useful shift in viewpoint.

Minimizing reconstruction error sounds like we are only thinking about what we lose. Maximizing projection sounds like we are thinking about what we keep. They are the same decision, just described from two different angles.

The next step is to rewrite the quantity \(\sum_i (x_i^\top w)^2\) in a compact form, because that will reveal what structure in the dataset actually decides the best direction \(w\).

Rewriting the objective with dimensions in mind

Let us slow down and pay attention to dimensions. Doing this carefully removes a lot of confusion later.

Each data point \(x_i\) lives in a \(d\)-dimensional space.

\[ x_i \in \mathbb{R}^d \]

The direction we are trying to learn, \(w\), also lives in the same space.

\[ w \in \mathbb{R}^d \quad \text{with } \|w\| = 1 \]

When we take the inner product \(x_i^\top w\), the result is a scalar. It measures how much of the point \(x_i\) lies along the direction \(w\).

\[ x_i^\top w \in \mathbb{R} \]

Our objective is built by squaring this scalar and summing over all points:

\[ \sum_{i=1}^{n} (x_i^\top w)^2 \]

This expression already makes sense dimensionally. Each term is a squared scalar. The sum is also a scalar.

However, to understand how the data as a whole influences this quantity, it helps to rewrite each term so that the role of the vector \(w\) is explicit.

Start with a single term:

\[ (x_i^\top w)^2 \]

Since this is a scalar, we are free to reorder the multiplication. Write it as:

\[ (x_i^\top w)(x_i^\top w) = w^\top (x_i x_i^\top) w \]

Now pay attention to the dimensions.

The outer product \(x_i x_i^\top\) takes a \(d\)-dimensional vector and produces a \(d \times d\) matrix:

\[ x_i x_i^\top \in \mathbb{R}^{d \times d} \]

When we place this matrix between \(w^\top\) and \(w\), the result is again a scalar:

\[ w^\top (x_i x_i^\top) w \in \mathbb{R} \]

This rewriting does not change the value of the expression. It only makes the dependence on the direction \(w\) explicit.

Now substitute this form back into the sum over all points:

\[ \sum_{i=1}^{n} (x_i^\top w)^2 = \sum_{i=1}^{n} w^\top (x_i x_i^\top) w \]

Because \(w\) does not depend on the index \(i\), we can factor it out of the summation:

\[ \sum_{i=1}^{n} w^\top (x_i x_i^\top) w = w^\top \left( \sum_{i=1}^{n} x_i x_i^\top \right) w \]

The matrix inside the parentheses is a \(d \times d\) matrix:

\[ \sum_{i=1}^{n} x_i x_i^\top \in \mathbb{R}^{d \times d} \]

It is constructed entirely from the data. Each data point contributes a rank-one matrix \(x_i x_i^\top\), and the dataset contributes their sum.

The objective can now be written compactly as:

\[ \max_{\|w\| = 1} \; w^\top \left( \sum_{i=1}^{n} x_i x_i^\top \right) w \]

Written this way, the problem becomes very clear. We are choosing a direction \(w \in \mathbb{R}^d\) that interacts with a \(d \times d\) matrix built from the data, and produces a scalar score measuring how much projection energy that direction captures.

In the next section, we will study this type of optimization problem directly. We will ask what kind of unit vectors maximize expressions of the form \(w^\top M w\), and why the answer has a very specific structure.

What choosing the “best direction” really means

Let us pause and look carefully at the problem we have ended up with. Not the symbols, but the decision we are actually making.

We have a dataset of points living in \( \mathbb{R}^d \). From that dataset, we built a matrix:

\[ M = \sum_{i=1}^{n} x_i x_i^\top \]

This matrix is not something we chose. It is forced on us by the algebra of projection. It is simply the object that collects, in one place, how the data spreads in space.

Now we are asked to choose a direction \(w\), with unit length, that maximizes the quantity:

\[ w^\top M w \]

What does this quantity actually do.

Pick a direction \(w\). Imagine fixing it in space. Now look at every data point and ask: how much of this point lies along that direction.

For a single point \(x_i\), that amount is given by \(x_i^\top w\). Squaring it removes sign and measures magnitude.

When we sum \((x_i^\top w)^2\) over all points, we are measuring how strongly the entire dataset aligns with the direction \(w\).

If most points have large components along \(w\), this sum will be large. If most points are nearly perpendicular to \(w\), this sum will be small.

Now imagine slowly rotating \(w\) while keeping its length fixed.

As you rotate it, the projections of the data points change. Some directions slice through the cloud of data and capture very little. Other directions pass through the long axis of the cloud and capture a lot.

The value of \(w^\top M w\) changes smoothly as you rotate \(w\). You can think of it as a score attached to each possible direction.

The unit-length constraint matters here. Without it, we could increase the score simply by scaling \(w\). By forcing \(\|w\| = 1\), we are saying something very specific: we are comparing directions, not magnitudes.

So the optimization problem is this.

Among all possible directions in \( \mathbb{R}^d \), which direction captures the largest total projection of the data.

It is important to notice that this problem must have an answer. The set of unit vectors is closed and bounded. The score \(w^\top M w\) varies continuously as we move \(w\).

That means there exists at least one direction where this score is maximized.

What is special about that direction is not that it minimizes error or maximizes variance. Those are descriptions we attach afterward.

What makes it special is simpler. If you choose any other direction, the dataset, when projected onto it, spreads out less.

The data itself decides this direction. We are not imposing it. We are only asking the data to tell us where it extends the most.

In the next section, we will see how this direction can be characterized exactly. We will see that the matrix \(M\) contains a small number of preferred directions, and that the optimal \(w\) must align with one of them.

Where we stand at the end of Blog 3

Let us take stock of what we have actually done so far.

We started this series by framing unsupervised learning as a compression problem. Not compression in the file-format sense, but in the sense of representing data using fewer numbers while still being able to reconstruct it reasonably well.

In Blog 2, we focused on a single point. We asked a very local question. If I am forced to represent this point using a line, where on that line should its proxy live. That question naturally led to projections and reconstruction error.

In this blog, we shifted the level of thinking. We stopped worrying about one point at a time and started worrying about the dataset as a whole.

Once we fix a direction \(w\), every point is automatically represented by its closest proxy on that direction. That leaves us with only one real choice. Which direction should we choose so that the total reconstruction error across all points is as small as possible.

We saw that minimizing reconstruction error is the same as maximizing how much of the data we keep when projecting onto a direction. This is not a change of objective. It is the same quantity viewed from two complementary perspectives.

Writing the problem carefully exposed its structure. The entire dataset influences the choice of direction through a single matrix built from outer products of the data points. This matrix summarizes how the data spreads in different directions.

At the end of Blog 3, we are left with a clean and precise question.

Among all unit directions in a high-dimensional space, which direction captures the largest total projection of the data.

Nothing in this reasoning required labels. Nothing required targets. Nothing required a notion of correctness. We only used geometry, reconstruction, and the idea of making the least damaging compression choice.

In the next blog, we will answer the question we have carefully set up. We will see how the matrix built from the data reveals its preferred directions, and why choosing one of those directions is not a heuristic, but a consequence of the optimization problem itself.
